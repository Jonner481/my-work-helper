🚀 1. Getting Started

Website Image Collector Pro helps you extract, organize, and analyze images from any website. Choose from three collection methods:

📄
Single Page Mode

Extract images from the current webpage only. Best for quick analysis of a single page.

Output: .txt file → Import/Parse
🤖
Website Crawler Mode

Scan entire websites including all pages, articles, and deep-linked content. Best for full site analysis.

Output: .txt file → Import/Parse
🔗
Direct URLs Mode

Manually add image URLs. Best for curating specific images or testing.

Direct input → Add URLs → Instant display
💡 Understanding the Workflow:
• Single Page & Crawler modes generate a .txt file that you import or paste back into the tool
• Direct URLs mode shows images immediately without file parsing
• All three modes let you save/load collections using Export/Import
• You can switch between modes without losing data (each mode has separate storage)

📄 2. Single Page Mode

Complete Guide:
  1. Navigate to the webpage you want to analyze in your browser
  2. Press F12 to open Developer Console
  3. In the tool, copy the entire "Single Page Mode" code (click "Copy Code")
  4. Paste the code into the console and press Enter
  5. The script will extract all images from the page
  6. A .txt file will automatically download to your computer
  7. METHOD 1 (EASIEST): Click the "Import TXT" button and select the downloaded file directly
  8. METHOD 2 (Manual): Open the file, copy all contents, paste into textarea, click "Parse Output"
  9. Your images will appear in the gallery automatically!
💡 Toggle Options:
• Extract CSS Background Images - Toggle ON/OFF to include or exclude CSS background images from extraction

🤖 3. Website Crawler Mode

Complete Guide:
  1. Go to the website's sitemap page (e.g., example.com/sitemap)
  2. Press F12 to open Developer Console
  3. Configure crawl settings:
    • Batch Size: 1 (slowest/safest), 2 (balanced), or 3 (fastest/uses more RAM)
    • Deep Scan: ON to follow links up to 2 levels deep (finds more pages)
    • Extract CSS: ON to include background images
  4. Copy the "Website Crawler" code and paste into console, press Enter
  5. The crawler will run and show progress in the console
  6. When complete, a .txt file will automatically download
  7. METHOD 1 (EASIEST): Click the "Import TXT" button and select the downloaded file directly
  8. METHOD 2 (Manual): Open file, copy contents, paste into textarea, click "Parse Output"
⚠️ Important Notes:
  • Large websites may take 5-15 minutes to crawl completely
  • Deep scan significantly increases crawl time but finds more pages
  • Type s() in console to re-download the .txt file if needed

🔗 4. Direct URLs Mode

How to use:
  1. Switch to the "Direct URLs" tab
  2. Paste image URLs (one per line) in the textarea
  3. Click "Add URLs to Gallery" to display images
  4. Images will appear in the gallery with automatic categorization

🎯 6. Filters & Sorting

Filters (Click to apply):
📊 All - Show all images
🖼️ HTML - Images from <img> tags
🎨 CSS - CSS background images
🌐 External - Images from other domains

💾 7. Import/Export Data

📥 Import TXT File
  1. Click the "📂 Import TXT" button in the Gallery Controls section
  2. Select a .txt or .json file from your computer
  3. The tool automatically detects the file format and imports all images
  4. Supports Single Page (CSP), Crawler (CWC), and exported collection files
📤 Export Data
  1. Click the "Export Data (TXT)" button
  2. A .txt file downloads with filename: [MODE]-[DOMAIN]-[DATE].txt
  3. Contains all image URLs, sources, alt text, categories, and selections
💡 Import/Export Tips:
  • Import adds data to existing collection (use "Clear Data" for a fresh start)
  • Export saves your work progress - especially useful after cleaning duplicates
  • You can export from one mode and import to another

🔧 12. Troubleshooting

❓ Images are not loading?
Check if the website blocks hotlinking or has CORS restrictions. Broken images will appear with red borders and in the "Broken" filter.
❓ Crawler is stuck or slow?
Reduce batch size to 1 page at a time. Disable deep scan for faster results.
❓ Duplicate count seems wrong?
Duplicates are counted per URL. Same image at different URLs counts separately.
❓ Import not working?
Ensure you're importing a file exported from this tool. The file should be .txt or .json format.
❓ Tooltip stays visible after deleting images?
The tooltip automatically hides when no images remain. Move your mouse away from the gallery area to reset.
❓ Selected popup not updating after delete?
The selected popup refreshes automatically when images are deleted from the main popup. If it doesn't, try closing and reopening.
