🚀 1. Getting Started

Website Image Collector Pro helps you extract, organize, and analyze images from any website. Choose from three collection methods:

📄
Single Page Mode

Extract images from the current webpage only. Best for quick analysis of a single page.

Output: .txt file → Paste → Parse
🤖
Website Crawler Mode

Scan entire websites including all pages, articles, and deep-linked content. Best for full site analysis.

Output: .txt file → Paste → Parse
🔗
Direct URLs Mode

Manually add image URLs. Best for curating specific images or testing.

Direct input → Add URLs → Instant display
💡 Understanding the Workflow:
• Single Page & Crawler modes generate a .txt file that you paste back into the tool
• Direct URLs mode shows images immediately without file parsing
• All three modes let you save/load collections using Export/Import
• You can switch between modes without losing data (each mode has separate storage)

📄 2. Single Page Mode

Complete Guide:
  1. Navigate to the webpage you want to analyze in your browser
  2. Press F12 to open Developer Console
  3. In the tool, copy the entire "Single Page Mode" code (click "Copy Code")
  4. Paste the code into the console and press Enter
  5. The script will extract all images from the page
  6. A .txt file will automatically download to your computer
  7. METHOD 1 (EASIEST): Click the "Import TXT" button and select the downloaded file directly
  8. METHOD 2 (Manual): Open the file, copy all contents, paste into textarea, click "Parse Output"
  9. Your images will appear in the gallery automatically!
💡 IMPORTANT: You don't need to copy-paste! Just use the "Import TXT" button to load the downloaded file directly.

🤖 3. Website Crawler Mode

Complete Guide:
  1. Go to the website's sitemap page (e.g., example.com/sitemap)
  2. Press F12 to open Developer Console
  3. Configure crawl settings
    • Batch Size: 1 (slowest/safest), 2 (balanced), or 3 (fastest/uses more RAM)
    • Deep Scan: ON to follow links up to 2 levels deep (finds more pages)
    • Extract CSS: ON to include background images
  4. Copy the "Website Crawler" code and paste into console, press Enter
  5. The crawler will run and show progress in the console
  6. When complete, a .txt file will automatically download
  7. METHOD 1 (EASIEST): Click the "Import TXT" button and select the downloaded file directly
  8. METHOD 2 (Manual): Open file, copy contents, paste into textarea, click "Parse Output"
  9. Your crawled images will appear in the gallery!
⚠️ Quick Tip: Use the 📂 Import TXT button - it's much faster than copy-pasting! The tool automatically detects the file format.
⚠️ Important Notes:
  • Large websites may take 5-15 minutes to crawl completely
  • Deep scan significantly increases crawl time but finds more pages
  • The loading indicator shows progress - don't close the console or navigate away
  • Type s() in console to re-download the .txt file if needed

🔗 4. Direct URLs Mode

How to use:
  1. Switch to the "Direct URLs" tab
  2. Paste image URLs (one per line) in the textarea
  3. Click "Add URLs to Gallery" to display images
  4. Images will appear in the gallery with tags and metadata
💡 Tip: You can paste URLs from any source - the tool will automatically detect and categorize images (logos, icons, stock photos, etc.)

🎯 6. Filters & Sorting

Filters:
📊 All - Show all images
🖼️ HTML - Images from <img> tags
🎨 CSS - CSS background images
🌐 External - Images from other domains
🔘 Icons - UI icons and small graphics
🏷️ Logos - Brand and company logos
🏠 Homepage - Images only on homepage
🔄 Similar - Groups of similar images
⚠️ Broken - Images that failed to load (404)
Sort Modes (Click the sort button to cycle):
  • ✨ Smart Sort - Failed images first → Numbers last → Stock last
  • ⚠️ Failed First - All broken images at the top
  • 🛒 Stock Last - Stock images (Shutterstock, Adobe, Envato) at bottom
  • 📁 No Sorting - Original order from parsing
💡 Tip: Filter badges show counts and have a ✕ button to delete all images of that type.

💾 7. Import/Export Data

📥 EASIEST WAY - Import TXT File Directly
  1. After running Single Page or Crawler script, a .txt file downloads automatically
  2. Instead of copy-pasting, simply click the "📂 Import TXT" button in the Gallery Controls section
  3. Select the downloaded .txt file from your computer
  4. The tool will automatically:
    • Read the file contents
    • Parse all images and metadata
    • Display everything in the gallery
    • No manual copy-paste needed!
✅ This works for:
  • Single Page Mode exports (CSP-*.txt files)
  • Website Crawler exports (CWC-*.txt files)
  • Previously exported collections (any .txt or .json file)
📋 Traditional Method (Copy-Paste)
  1. Open the downloaded .txt file with any text editor
  2. Press Ctrl+A to select all, then Ctrl+C to copy
  3. Paste into the textarea in the respective mode tab
  4. Click "Parse Output" to display images
📤 Export Data (Save your collection)
  1. Click the "Export Data (TXT)" button at the bottom of the sidebar
  2. A .txt file will automatically download with filename format: [MODE]-[DOMAIN]-[DATE].txt
  3. The file contains ALL your collected data including:
    • All image URLs with their sources (which pages they came from)
    • Alt text for each image occurrence
    • Image categories (HTML, CSS, external, icons, logos, stock)
    • Similar image groups
    • Your current selections and trashed items
  4. To restore later, simply click "Import TXT" and select the file
💡 Pro Tips for Import/Export:
  • No more copy-paste! Just use the Import TXT button for downloaded files
  • Export regularly to save your work progress - especially after cleaning up duplicates
  • You can export from Crawler mode and import to Direct URLs mode
  • Imported data is added to existing data, not replaced (use "Clear Data" first if you want a fresh start)
  • The Import TXT button accepts both .txt and .json files

💡 10. Pro Tips

  • Hover over any image to see the full URL in a custom tooltip
  • Broken images automatically appear at the top when Smart Sort, Failed First, or Stock Last modes are active
  • Use Shift+Click on checkboxes to select multiple images in a row
  • Filter badges have a ✕ button to delete all images of that type at once
  • Stock images are detected by domain and numeric ID patterns (Shutterstock, Adobe, Envato)
  • Similar images are grouped based on filename patterns (e.g., image-1.jpg, image-2.jpg)
  • Export your collection regularly to save your work progress
  • Use Deep Scan for complete website crawling (finds pages linked from sitemap)
  • Toggle CSS extraction OFF for faster crawling if you only need HTML images

🔧 11. Troubleshooting

❓ Images are not loading?
Check if the website blocks hotlinking or has CORS restrictions. Broken images will appear with red borders.
❓ Crawler is stuck or slow?
Reduce batch size to 1 page at a time. Disable deep scan for faster results.
❓ Duplicate count seems wrong?
Duplicates are counted per URL. Same image at different URLs counts separately.
❓ Import not working?
Ensure you're importing a file exported from this tool. The file should be .txt or .json format.
❓ Stock images not detected?
Stock detection works on domain names and filename patterns. Custom URLs may not be detected.
