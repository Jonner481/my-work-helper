📸 Website Image Collector

Extract and view all images from any webpage

📖 Quick Start Guide

Method 1 - Single Page (Quick):
1. Copy the "Single Page Mode" code below
2. Paste in console → Press Enter
3. Copy output → Paste in "Console Output" → Click "Parse Output"

Method 2 - Full Website Crawler:
1. Go to website → Copy "Website Crawler" code → Run in console
2. Download .txt file → Paste contents → Click "Parse Output"

Method 3 - Direct URLs:
• Switch to "Direct URLs" tab → Paste image URLs → Click "Add URLs"

💡 Features:
• ← → arrow keys to navigate in popup
• Ctrl+Z / Ctrl+Y for Undo/Redo

📋 How to Use Single Page Mode:

  1. Copy the code below (click "Copy Code")
  2. Press F12 to open Developer Console
  3. Paste into console and press Enter
  4. The script will extract ALL images from the current page
  5. Copy the entire console output (from "━━━━━━ START ━━━━━━" to "━━━━━━ END ━━━━━━")
  6. Paste below and click "Parse Output" to see gallery
🎨 Extract CSS Background Images
✅ ON = Extracts <img> tags + CSS backgrounds
🔘 OFF = Only <img> tags

📋 How to Use Website Crawler:

  1. Go to the sitemap page: https://example.com/sitemap
  2. Press F12 to open Developer Console
  3. Select batch size below (1-3, default 2)
  4. Copy the code below (click "Copy Code")
  5. Paste into console and press Enter
  6. The crawler will run and download a .txt file with all results
  7. Open the downloaded file and copy ALL its contents
  8. Paste below and click "Parse Output" to see gallery
Lower = more stable, Higher = faster
🎨 Extract CSS Background Images
✅ ON = Extracts <img> tags + CSS backgrounds
🔘 OFF = Only <img> tags

🔗 How to Use Direct URLs:

  1. Paste image URLs (one per line) in the textarea below
  2. Click "Add URLs to Gallery" to display images
  3. Use filters and selection tools to organize
  4. Export your collection using "Export Data"
